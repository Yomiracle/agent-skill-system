# case-001-basic-review: 基本合同审查能力验证

## 输入
```yaml
contract_text: |
  股权代持协议

  委托方（以下简称甲方）：
  身份证号：

  受托方（以下简称乙方）：
  身份证号：

  甲乙双方本着平等互利的原则，友好协商，就甲方委托乙方代为持股事宜达成如下协议，以兹共同遵守：
  一、委托内容
  甲方自愿委托乙方作为自己对【X公司】认缴出资人民币（币种，下同）100万元（￥1,000,000元，该等出资占公司注册资本的20%）的名义持有人，并代为行使相关股东权利，乙方愿意接受甲方的委托并行使相关股东权利。
  二、委托期限
  乙方根据甲方授权行使由上述股权形成的股东权利。甲方持有股权及委托乙方代持股权的期限为：自本协议签订之日起3年，有效期届满后双方未提出异议的，本协议自动续期。

party_role: 甲方
```

## 期望输出检查

### 结构检查
- [ ] output 包含"逐条分析"（或等效结构）
- [ ] output 包含修改清单（优先级分级）
- [ ] output 每条修改建议附带可操作的改法文本

### 内容检查（关键断言）
- [ ] 第二条"自动续期"被标记为风险（🔴极高或🟠高优先级）
- [ ] 审查意见中出现了"单方解除权"的建议
- [ ] 建议的修改文本包含具体的通知期限（如"30日前书面通知"）

### 边界检查
- [ ] 没有出现"24%"作为违约金司法标准
- [ ] 没有出现"民间借贷"与违约金的交叉引用
