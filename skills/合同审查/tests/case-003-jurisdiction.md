# case-003-jurisdiction: 管辖条款双刃剑识别

## 输入
```yaml
contract_text: |
  合作协议
  ...
  九、争议的解决
  甲、乙双方因履行本协议所发生的争议均应友好协商解决，协商不成的，任何一方可向原告所在地人民法院起诉。
  ...
  注：协议涉及公司股权事项。

party_role: 甲方
```

## 期望输出检查

### 内容检查（关键断言）
- [ ] 明确指出了"原告所在地"管辖约定的风险
- [ ] 解释了为什么该约定在公司类纠纷中可能无效
- [ ] 提到了"公司住所地专属管辖"或等效表述

### 建议检查
- [ ] 至少给出了一个替代方案（仲裁 或 甲方住所地法院）
- [ ] 替代方案附带了理由说明

### 边界检查
- [ ] 没有简单地说"原告所在地对你有利就用这个"（这是会给自己挖坑的简化建议）
- [ ] 推荐的替代方案没有排除例外情形（如"一定能"这类绝对化表述）
