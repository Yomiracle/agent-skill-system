# 技能记忆：Bug诊断与修复

## 有效经验

### 2026-06-11 [成功] 技能蒸馏——从实际开发中的6个bug提取模式
- 场景：C1-C4引擎开发过程中连续踩了6类bug，全部修复后蒸馏为技能
- 做法：收集每次报错→定位→修复→验证的完整链路，提炼为6种已知失效模式
- 要点：报错是水，模式是渠——把同类错误结构化后，下次匹配即修复

### 2026-06-11 [成功] 模式识别加速修复
- 场景：test_c1_hard.py 中变量 bank/searcher 被临时目录污染导致 T11 T12 挂
- 做法：识别为模式B（变量跨测试污染），5分钟内定位全部污染路径
- 要点：污染通常发生在集成测试中——前一步创建了带状态的临时对象，后一步默认引用

### 2026-06-11 [成功] re.match → re.search 批量修
- 场景：C2 TestRunner._evaluate 中8处 re.match 在中文断言场景全挂
- 做法：识别为模式A，全文搜索所有 re.match 并判断是否需要改为 re.search
- 要点：re.match(string) 等价于 re.search('^' + pattern, string)，两者语义差异是高频错误源

### 2026-06-11 [失败] f-string中文引号被Python误解
- 场景：test_c1_hard.py 第45行，print(f'\n   任务："{task}"') 在中文引号处报 SyntaxError
- 错误：中文" "被Python解析器误读为字符串边界
- 根因：f-string 内层用了英文`"`引号，外层也用了`""`，中英文引号 Unicode 混用
- 修正：改用 `'` 单引号包裹 f-string 外层，内层保留中文引号
