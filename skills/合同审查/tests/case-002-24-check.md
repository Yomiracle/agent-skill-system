# case-002-24-check: 违约金审查不引用24%旧规

## 输入
```yaml
contract_text: |
  供应合同
  ...
  第七条 违约责任
  乙方逾期交货的，每逾期一日按未交货金额的日万分之五向甲方支付违约金。
  乙方擅自解除合同的，应按合同总金额的30%向甲方支付违约金。
  ...

party_role: 甲方
concerns: 违约金
```

## 期望输出检查

### 内容检查（关键断言）
- [ ] 分析日万分之五时，计算了年化利率（约18.25%）
- [ ] 违约金建议引用了《民法典》第585条，或《合同编通则解释》第65条
- [ ] 可选但鼓励：提到LPR四倍标准

### 边界检查（硬禁止）
- [ ] "24%"这个词出现次数 = 0
- [ ] 没有出现"民间借贷利率保护上限"用于解释违约金
- [ ] 没有声称"年化X%以内容法院不主动调低"

### 替代表述检查
- [ ] 关于违约金司法上限的表述，至少出现了以下之一：
  - "过分高于造成损失的30%"的表述
  - "LPR四倍"的表述
  - 《民法典》第585条的明确引用
